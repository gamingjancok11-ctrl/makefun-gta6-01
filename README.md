**CALDERA BAY — Heat on the Black Sand.** An open-world crime game in the spirit of GTA 6, built with three.js: a sun-soaked volcanic island city with 9 districts, 8 story missions, a 5-star wanted system with police pursuits, roadblocks and a searchlight helicopter, car theft and arcade driving, on-foot combat, street races, taxi fares, 20 Sunset Tapes, shops, a safehouse, procedural radio and save/load — all playable offline in a desktop browser.

## Run it

```sh
node serve.ts
# then open http://localhost:8080
```

Controls: WASD move & drive · mouse look · E enter car / interact · click shoot · R reload · 1–5 weapons · Q radio · M start next mission · Esc map & pause.

Screenshots are staged through the game's own code: `?shot=chase|fight|race|map&seed=7`.
